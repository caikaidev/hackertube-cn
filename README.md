# HackerTube CN

从 V2EX 的高互动帖子里，把网友们**真正推荐过、夸过**的视频博主挖出来，做成一个可搜索的索引站。

- 线上站点：https://hackertube-cn.pages.dev
- 纯外链：本站不托管、不嵌入任何视频，点卡片直接去 B 站 / YouTube 看原视频。
- 无账号、无后端：一个静态页面 + 一份 JSON 数据。

## 数据是怎么来的

1. **种子帖**：V2EX 上「有哪些值得关注的 XX 博主 / UP 主」类高互动帖子。
2. **全量抓取**：通过 V2EX 官方 API 抓下整帖全部楼层，并在本地重建回复关系（`#楼层` 引用优先、`@用户` 挂最近一条更早回复兜底）。
3. **模型提取**：用 LLM 从评论中提取被提到的博主 / 视频，记录提及人数与正面推荐的楼层作为证据。
4. **程序校验**（这一步是硬的，不靠模型自觉）：
   - 博主名必须能逐字在来源帖原文中命中，命中不了的一律丢弃（防模型编造）；
   - 主页链接只认原文里出现的链接，禁止推断拼接，没有链接就给站内搜索入口；
   - 证据重算：入选需要 ≥2 位不同用户提及且有正面信号，或 ≥5 人提及。

管线代码在 `pipeline/`，方案细节见 `MVP方案-v0.2.md`，每轮提取的审计记录见 `样本报告-v1.md` / `样本报告-v2.md`。

## 收录口径

- **先全收**：达到证据门槛的都收，分类与排序在站点侧持续调整，不在提取阶段删减。
- **时政类默认不收**：名单在 `data/excluded_politics.json`，公开可查、可审计；有异议开 issue 讨论。
- **自荐会标明**：博主本人到帖子里推荐自己的，数据里带 `self_promo` 标记，页面上可见。
- 数据文件 `data/data.json` 每条都带来源帖 ID 与证据楼层，可逐条回溯原文核对。

## 删除与纠正

如果你是被收录的博主，或发现某条信息有误（名字、链接、分类不对），开一个 issue 说明即可，会尽快删除或修正。数据来自公开帖子，本站只做提炼索引，不转载评论全文。

## 目录

```
site/       静态站点（index.html 内嵌数据，data.json 为同份副本）
data/       data.json（正式数据） / excluded_politics.json（时政排除名单）
pipeline/   抓取 → 解析 → 提取 → 合并 → 建站脚本
```

本地预览：直接用浏览器打开 `site/index.html` 即可。
